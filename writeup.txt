PROJECT SUMMARY WRITE-UP (For Assignment Book Submission):

In this project, we designed, implemented, and analyzed a Convolutional Neural Network (CNN) in Python and TensorFlow/Keras to perform binary visual classification determining whether an individual is wearing a safety helmet/mask or not. The architecture processes 128x128 RGB images through hierarchical feature extraction layers: starting with 3x3 convolution kernels that capture low-level edge and boundary responses, non-linear activation via Rectified Linear Units (ReLU) to eliminate negative responses, and 2x2 Max-Pooling stages to compress spatial dimensions and achieve translation invariance. Deeper convolutional blocks progressively aggregate low-level edges into mid-level geometric curves and high-level contextual headgear patterns before passing flattened representations through a Dense layer with dropout regularization and a Sigmoid output classifier. Evaluated on a balanced test dataset, the trained CNN achieved 78.00% test accuracy (loss: 0.5148) with balanced precision and recall across both classes, visually and quantitatively verifying how deep convolutional layers progressively extract hierarchical visual features for automated safety gear detection.
